# Security policy

USB Edge is not released. Report potential security issues privately to the maintainers; do not publish exploitable operational details, keys or sensitive captures. Review public-safe source and evidence before publication. No production credentials, private device data or hardware access in this repository. Generic software release requires actual managed-exporter and restoration acceptance; Pi-branded hardware release separately requires real board qualification. Inventory/package PASS is not USB/IP or HIL PASS.
