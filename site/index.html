SemperSupra · Virtual USB

USB Edge

A Linux and ARM64 peripheral appliance for read-only USB inventory and, when qualified, managed export and restoration.

Release status

Pre-release documentation. No production release or installable distribution is announced here. Do not treat development builds as qualified releases.

Scope

Read-only inventory first; managed exporter and restoration are separate acceptance gates.

Qualification

Inventory and package checks do not establish physical hardware or managed exporter qualification.

Source and releases

See the public repository for the current source status and GitHub Releases for any published distribution. Release instructions will accompany the applicable version.

Reproduce this documentation

From a checkout of the public repository, run python3 -I scripts/build-public-pages.py /tmp/public-site-new. The output directory must not already exist. Open its index.html in a browser. This command builds documentation only, not the product.

Documentation only. No physical-device, production or runtime claims.
